# Agent Instructions for the Skills Mirror

Read `AGENTS.md` before working in this repository.

Generic Perl skills are under `perl_agents/skills/`. XPerl-specific skills
are under `xperl_agents/skills/` and apply only to XPerl checkouts. The canonical
source is `../perl/.agents/skills/`.

Make guidance changes in `AGENTS.md`; this file is its concise pointer.
